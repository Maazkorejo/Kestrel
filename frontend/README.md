# Kestrel AI Frontend Studio

**Tagline:** Hunt flaws. Ship armor.

The frontend client for **Kestrel AI**, an AI-native cybersecurity studio and desktop IDE built for proactive vulnerability discovery, AST static analysis, NVIDIA Nemotron remediation, and isolated container exploit verification.

---

## 1. Core Capabilities & Workspace Layout

* **Workspace File Explorer:** Native desktop filesystem tree with breadcrumb folder navigation (Desktop, Downloads, custom directories) and live file synchronization.
* **Monaco Code Editor:** Integrated `@monaco-editor/react` with full syntax highlighting, code folding, minimap, and AST diagnostic markers (red squiggly underlines) pinpointing vulnerable code blocks.
* **Multi-Tab Intelligence & Defense Center:**
  * **Findings & Threat Intel:** CWE classifications, severity badges, and live CVE advisories fetched dynamically via Tavily Search API.
  * **AI Remediation & Diff:** Plain-English root cause breakdowns and side-by-side or unified diffs generated by NVIDIA Nemotron, with one-click "Apply Patch to Disk".
  * **Docker Exploit Sandbox:** Containerized verification console executing simulated proof-of-concept exploits safely before and after remediation.
  * **STRIDE Threat Modeling:** Visual attack tree representation mapping architectural surfaces to vulnerable code blocks.
  * **CI/CD Generator:** One-click export of automated GitHub Actions and GitLab CI security gates.
* **Production Authentication Modal:** Clean OAuth 2.0 PKCE sign-in supporting Google, GitHub, and email/password with persistent local session management.

---

## 2. Technology Stack

* **Framework:** React with TypeScript and Vite
* **Code Editor:** Monaco Editor (`@monaco-editor/react`)
* **Styling:** Tailwind CSS with Dark Obsidian Cyber Theme
* **Icons:** Lucide React (`lucide-react`)
* **Diff Utilities:** `diff` and custom side-by-side visualizers
* **Routing:** TanStack Router / Start

---

## 3. Local Development

Ensure you have Node.js 18+ and npm installed.

```bash
# Install frontend dependencies
npm install

# Start the Vite development server (defaults to port 8080 or 5173)
npm run dev

# Build production assets
npm run build
```

---

## 4. Backend Communication

The frontend connects directly to the modular FastAPI backend services:
* **Internal APIs (`/api/internal`):** File system browsing, file read/write, terminal command execution, and OAuth credentials.
* **External APIs (`/api/external`):** AST static analysis scans, SSE audit streaming, Tavily CVE lookups, Nemotron AI remediation, Docker sandbox runs, and CI/CD workflow generation.
