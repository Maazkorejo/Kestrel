# API Specification & Data Contracts

## Project: SecStudio AI (AI-Native Cybersecurity IDE)

---

## 1. Overview
This document defines the strict REST API contracts and JSON schemas used between the FastAPI backend and the React/Monaco frontend. All models follow Pydantic v2 conventions on the backend and correspond to TypeScript interfaces on the frontend.

---

## 2. Common Data Schemas

### 2.1 Vulnerability Finding Model (`Finding`)
Represents an individual security finding generated by deterministic static analysis engines.

```json
{
  "id": "vuln_01",
  "rule_id": "bandit-B608-sql-injection",
  "title": "SQL Injection via Unsanitized Formatting",
  "description": "Direct string concatenation into SQL query allows unauthorized query execution or authentication bypass.",
  "cwe_id": "CWE-89",
  "severity": "CRITICAL",
  "line_start": 23,
  "line_end": 23,
  "code_snippet": "query = f\"SELECT id, username, role FROM users WHERE username = '{username}'\"",
  "scanner": "bandit"
}
```

* **Severity Levels:** `CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFORMATIONAL`

### 2.2 Threat Intelligence Item (`ThreatRecord`)
Represents authoritative vulnerability data fetched in real time via Tavily.

```json
{
  "cve_id": "CVE-2023-XXXX",
  "title": "SQL Injection in SQLite Driver Implementations",
  "source_url": "https://nvd.nist.gov/vuln/detail/CVE-2023-XXXX",
  "published_date": "2023-11-15",
  "summary": "Improper neutralization of special elements in query construction leads to arbitrary query manipulation.",
  "cvss_score": 9.8,
  "mitigation": "Use parameterized queries with placeholder substitution tuples rather than formatted string literals."
}
```

### 2.3 Remediation Patch Model (`RemediationResult`)
Represents the AI reasoning breakdown and patch output produced by Nemotron.

```json
{
  "finding_id": "vuln_01",
  "root_cause": "The username variable is formatted directly into the SQL query string without escaping or parameter binding.",
  "exploit_scenario": "An attacker can input `' OR '1'='1` in the username field to bypass password verification and gain administrative access.",
  "patch_summary": "Replaced direct f-string formatting with parameterized query markers and passed parameters as a tuple.",
  "diff": "--- a/auth_service.py\n+++ b/auth_service.py\n@@ -21,3 +21,3 @@\n-    query = f\"SELECT id, username, role FROM users WHERE username = '{username}'\"\n-    cursor.execute(query)\n+    query = \"SELECT id, username, role FROM users WHERE username = ? AND password = ?\"\n+    cursor.execute(query, (username, password))\n",
  "patched_full_code": "..."
}
```

## 3. API Endpoints

### 3.1 `POST /api/scan/static`
Runs deterministic AST and regex scanners against the provided code snippet.

* **Request Body (`ScanRequest`):**
```json
{
  "filename": "auth_service.py",
  "language": "python",
  "code": "import sqlite3\n..."
}
```

* **Success Response (`200 OK` - `ScanResponse`):**
```json
{
  "code_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "total_findings": 1,
  "severities": {
    "CRITICAL": 1,
    "HIGH": 0,
    "MEDIUM": 0,
    "LOW": 0
  },
  "findings": [
    {
      "id": "vuln_01",
      "rule_id": "bandit-B608-sql-injection",
      "title": "SQL Injection via Unsanitized Formatting",
      "cwe_id": "CWE-89",
      "severity": "CRITICAL",
      "line_start": 23,
      "line_end": 23,
      "code_snippet": "query = f\"SELECT id, username...\"",
      "scanner": "bandit"
    }
  ]
}
```

---

### 3.2 `POST /api/intel/cve`
Queries authoritative databases via Tavily for the latest threat intelligence on a detected CWE or package.

* **Request Body (`ThreatIntelRequest`):**
```json
{
  "cwe_id": "CWE-89",
  "keyword": "sqlite python parameterization"
}
```

* **Success Response (`200 OK` - `ThreatIntelResponse`):**
```json
{
  "query": "CWE-89 sqlite python parameterization mitigation",
  "records": [
    {
      "cve_id": "CVE-2023-XXXX",
      "title": "Improper neutralization of special elements in SQLite query construction",
      "source_url": "https://nvd.nist.gov/vuln/detail/CVE-2023-XXXX",
      "summary": "Parameterization is required to prevent bypass of authentication checks.",
      "cvss_score": 9.8,
      "mitigation": "Utilize question mark parameter placeholders."
    }
  ]
}
```

---

### 3.3 `POST /api/remediate`
Sends the finding, code context, and threat intelligence to Nemotron to generate an explanation and code patch.

* **Request Body (`RemediateRequest`):**
```json
{
  "filename": "auth_service.py",
  "language": "python",
  "code": "...",
  "finding": {
    "id": "vuln_01",
    "cwe_id": "CWE-89",
    "title": "SQL Injection",
    "line_start": 23,
    "line_end": 23,
    "code_snippet": "..."
  },
  "threat_intel": {
    "summary": "Use parameterized queries with placeholder tuples."
  }
}
```

* **Success Response (`200 OK` - `RemediationResponse`):**
```json
{
  "finding_id": "vuln_01",
  "root_cause": "The query was constructed using unescaped string formatting.",
  "exploit_scenario": "Arbitrary SQL commands can be injected via input parameters.",
  "patch_summary": "Converted query string to parameterized statement.",
  "diff": "--- a/auth_service.py\n+++ b/auth_service.py...",
  "patched_full_code": "..."
}
```

---

### 3.4 `POST /api/scan/full`
Convenience orchestration endpoint that runs static analysis, queries Tavily, and triggers Nemotron reasoning in a single coordinated pipeline.

* **Request Body:** Identical to `ScanRequest`.
* **Success Response (`200 OK`):** Contains `findings`, `threat_intel_map`, and `remediation_map`.
